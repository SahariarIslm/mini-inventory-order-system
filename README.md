# Mini Inventory & Order System

Laravel API + React (TypeScript) technical assessment for Akaar IT Ltd.

Two customers can try to buy the last unit of the same product at the same
moment — this system guarantees only one order succeeds, by design.

## Structure
- `backend/` — Laravel API
- `frontend/` — React + TypeScript SPA
- `docker/` — supporting container configs
